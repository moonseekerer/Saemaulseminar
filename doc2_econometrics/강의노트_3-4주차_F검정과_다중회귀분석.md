## 1. 가성회귀(Spurious Regression)와 결정계수($R^2$)에 대한 학술적 고찰

### 1.1 아프리카 코끼리 개체 수와 한국 경제성장률의 비유
* 시계열 데이터(Time Series)에서 단위근(Unit Root)이나 추세(Trend)를 지닌 무관한 두 변수를 회귀분석하면, 통계적으로 매우 높은 $R^2$와 유의한 $t$-값이 도출되는 현상.
* **학술적 교훈**: 사회과학 연구자는 높은 $R^2$에 현혹되지 말고, 두 변수 간 실질적인 인과 매커니즘(Causal Mechanism)과 시계열 안정성(Stationarity)을 엄밀히 검증해야 함.

### 1.2 사회과학 연구에서 높은 $R^2$에 대한 의심
* 복잡다단한 인간 행동 및 사회현상을 2~3개의 단순 변수로 90% 이상 설명한다는 것은 이론적으로 불가능에 가까움.
* $R^2$가 지나치게 높다면(예: 0.8~0.9 이상) **(1) 가성회귀**, **(2) 다중공선성(Multicollinearity)**, **(3) 동시성 편향(Simultaneity Bias)**, **(4) 과적합(Overfitting)** 등을 강력히 의심해야 함.

### 1.3 표본 크기($N$)와 $R^2$의 기하학적 거동
* **$N = 2$인 경우**: 2차원 평면에서 두 점은 직선 하나를 유일하게 결정하므로, 오차 제곱합($SSE$)이 0이 되어 무조건 $R^2 = 1.0$ (100%)가 됨.
* **$N \to \infty$인 경우**: 관측치가 누적될수록 개인 간 무작위 이질성(Unobserved Heterogeneity)과 잡음(Noise)이 반영되므로 실증 데이터에서 $R^2$는 필연적으로 하락함. 따라서 대규모 미시 표본에서 $R^2$가 0.1~0.3 수준이어도 모형이 유의미하다면 충분히 학술적 가치를 지님.

## 2. $F$-검정(F-test)의 본질과 모형 전체의 유의성

### 2.1 $F$-통계량의 직관적 정의 (신호 대 잡음비, Signal-to-Noise Ratio)
교수님 직관 설명: **"설명된 변동에서 설명 안 된 변동을 나누어, 모형이 잡음 대비 몇 배를 설명해냈는가?"**

$$F = \frac{\text{모형이 설명한 변동 (자유도 조정)}}{\text{설명되지 못한 오차 변동 (자유도 조정)}} = \frac{MSR}{MSE} = \frac{R^2 / k}{(1 - R^2) / (n - k - 1)}$$

* **$F \approx 1$**: 설명된 변동이 순수 무작위 잡음 수준에 불과함 $\rightarrow$ 모형이 무의미함 ($H_0$ 채택).
* **$F \ge 3 \sim 4$**: 통상 유의수준 5%($p < 0.05$)에서 모형 전체가 유의해지기 시작함.
* **$F > 10$**: 모형이 잡음 대비 10배 이상의 설명력을 확보하여 매우 견고하게 유의미함.

### 2.2 가설 설정의 엄밀성 (교수님 강의 중 구두 정정 반영)
* **강의자료 PDF 표기**: $H_0: R^2 = 0 \quad \text{vs} \quad H_1: R^2 \neq 0$
* **수리통계학적 정정**: $R^2 = \frac{SSE}{SST} \ge 0$이므로 결정계수는 **오직 양수로만 존재**함. 음수가 될 수 없으므로 대립가설은 반드시 **우측 단측 검정(Right-tailed test)** 형태인 **$H_1: R^2 > 0$**이어야 함. 기각역 역시 우측 꼬리에만 형성됨.
* **회귀계수 결합가설**: $H_0: \beta_1 = \beta_2 = \dots = \beta_k = 0 \quad \text{vs} \quad H_1: \text{적어도 하나의 } \beta_j \neq 0$

### 2.3 $F$-검정이 개별 $t$-검정의 단순 나열보다 필수적인 이유
1. **1종 오류(Type I Error)의 누적 방지**: 유의수준 5%에서 $k$개의 독립변수를 개별 검정 시, 최소 하나가 우연히 유의하게 나올 결합오류율은 $1 - (1 - \alpha)^k$로 급증함 ($k=2$일 때 약 9.75%).
2. **다중공선성(Multicollinearity) 하의 결합 설명력 포착**:
   * *왼발 크기($X_1$)와 오른발 크기($X_2$)로 키($Y$)를 설명하는 사례*:
   * 두 변수가 강하게 상관되어 개별 $t$-검정은 둘 다 비유의적으로 나올 수 있으나, 두 변수의 '공동 설명력'은 매우 강력하므로 $F$-검정은 모형 전체가 매우 유의($p < 0.001$)하다고 정확히 판정함.
   * 따라서 실증분석 절차는 **"선(先) $F$-검정(전체 유의성 확인) $\rightarrow$ 후(後) $t$-검정(개별 한계효과 검토)"** 순서로 진행해야 함.

## 3. 실습 데이터: 임금 다중회귀분석 ($N=20$)

### 3.1 원시 데이터 요약 (Raw Data)
* 관측치 $N=20$, 종속변수: $WAGE$(임금, 만원), 독립변수: $EDU$(교육연수, 년), $AGE$(나이, 세), $GENDER$(더미변수: 남성 1, 여성 0)

### 3.2 선형 회귀모형 (Linear Model): $WAGE = \beta_0 + \beta_1 EDU + \beta_2 AGE + u$
* **모형 적합도**:
  * $N = 20$, $R^2 = 0.5168$ (51.68%), 수정된 $R^2 = 0.4600$
  * $F\text{-통계량} = 9.0919 \quad (p\text{-value} = 0.0021^{***})$ $\rightarrow$ 모형 전체가 1% 유의수준에서 매우 유의함.
* **추정 계수**:
  * $\beta_0 (\text{상수항}) = -41.0730 \ (SE = 46.9338, \ t = -0.875, \ p = 0.3937)$
  * $\beta_1 (\text{EDU}) = 9.1681 \ (SE = 2.7824, \ t = 3.295, \ p = 0.0043^{***})$ $\rightarrow$ 교육연수 1년 증가 시 임금 약 9.17만 원 상승.
  * $\beta_2 (\text{AGE}) = 1.5846 \ (SE = 0.8064, \ t = 1.965, \ p = 0.0660^{*})$ $\rightarrow$ 나이 1세 증가 시 임금 약 1.58만 원 상승 (10% 유의).

## 4. 자연로그 변환 모형 및 잔차 분석 (Residual Diagnostics)

### 4.1 더미변수와 자연로그의 성질
* **더미변수의 로그 변환 불가**: 성별(GENDER)은 0과 1로 코딩되므로 $\ln(0) = -\infty$가 되어 수학적으로 정의되지 않음. 따라서 더미변수는 원형 그대로 투입함.
* **자연로그의 스케일 한계**:
  * 수학적으로 $\ln(x)$는 상한이 없으나, $\ln(x) = 10 \iff x = e^{10} \approx 22,026$임.
  * 사회과학의 개인 단위 데이터(월급 만원 단위, 연령, 교육연수 등)에서 관측치가 22,000을 넘는 경우는 극히 드물므로, **실무 데이터에서 자연로그 변환값은 0 ~ 9(통상 3 ~ 7) 범위 내에 머물며 10을 넘지 않음**.

### 4.2 로그 회귀모형 추정 결과 (Log-Log with GENDER Dummy)
$$\ln(WAGE) = \beta_0 + \beta_1 \ln(EDU) + \beta_2 \ln(AGE) + \beta_3 GENDER + u$$

* **모형 적합도**: $R^2 = 0.6559$, 수정된 $R^2 = 0.5914$, $F = 10.1656 \ (p = 0.0005^{***})$
* **계수 해석 (탄력도, Elasticity)**:
  * $\ln(EDU)$: 탄력도 **0.9165** ($t=3.899, \ p=0.0013$) $\rightarrow$ 교육연수가 1% 증가할 때 임금은 약 0.92% 증가.
  * $\ln(AGE)$: 탄력도 **0.4589** ($t=2.630, \ p=0.0182$) $\rightarrow$ 나이가 1% 증가할 때 임금은 약 0.46% 증가.
  * $GENDER$: 계수 **0.1449** ($t=1.651, \ p=0.1182$) $\rightarrow$ 여성 대비 남성의 임금이 약 14.5% 높은 경향.

   * 잔차가 0을 중심으로 위아래 고르게 분포(등분산성 확보)하여 OLS 기본 가정을 훨씬 더 충실히 만족함.
